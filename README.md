# Тур-гид по Астане

## Описание проекта

Тур-гид по Астане — это веб-сайт для знакомства с достопримечательностями столицы Казахстана. Пользователи могут просматривать интересные места, читать информацию о них и добавлять новые достопримечательности.

## Функциональность

- Просмотр достопримечательностей.
- Подробная информация о каждом месте.
- Добавление новых мест через форму.
- Проверка введённых данных.
- Сохранение информации в JSON-файле.
- Отображение фотографий.
- Страницы «О проекте» и 404.

## Установка и запуск

**1. Установите зависимости:**

```bash
npm install
```

**2. Запустите сервер:**

```bash
npm start
```

**3. Откройте сайт в браузере:**

http://localhost:3000
